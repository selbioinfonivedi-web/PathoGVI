Sequences must already be aligned. Every position-wise index (π, MB, GD, dN/dS, μ) assumes column i is homologous across all sequences.

Gates CAI — a host codon table only means something for an organism that translates on host ribosomes.

Sets the ceiling μ is normalised against. A DNA rate judged on the RNA scale contributes almost nothing however fast it is for a DNA genome.

Organism class and genome type are unset. Neither can be inferred from sequence and both change what the numbers mean. The run will proceed, but CAI is computed on an unverified assumption and μ is judged on the RNA scale.

Columns: sequence_id, collection_date, location, host. Without dates μ cannot be estimated at all.

CDS features. Without it both coding indices are skipped.

CAI measures adaptation to the host's translational machinery, so pick the host this pathogen infects.

The birth–death process is scaled by 365.25 / generation time, so a value wrong by a factor of k moves Re by roughly the same factor — and Re carries the largest weight in the scheme. Left empty, the run uses 5 days, which suits a fast respiratory virus and little else.

Columns: date, new_cases. With real case counts Re is estimated by the Cori renewal equation, which recovers a known Re to within 0.02. Without them Re is inferred from tree shape alone, which is far weaker.

Advanced — estimator selection, reference, distance method

MB and GD are measured against this record.

GC deviation is measured from this baseline. Left empty it uses the alignment's own reference sequence, which measures deviation from this dataset rather than from an external host-genome target.

The non-default options re-optimize branch lengths, dates, or per-branch rates by maximum likelihood; falls back to Auto on its own size cap or on unavailable dates, with a warning. The relaxed clock additionally reports a rate coefficient of variation among branches.

The ML codon model fits a 61-state substitution model per gene; can take noticeably longer on long or many-gene GFFs.

Ignored when a case-incidence CSV is supplied above (Cori estimator always wins then). Auto already falls back to this weaker regression on its own if the birth-death fit fails or the tree exceeds its taxon cap.

The default weights are the specification's asserted midpoints, not fitted against any outcome. Any index you don't set below keeps its default, and the full set of 9 is renormalized to sum to 1 automatically.

Unchecked indices are skipped entirely rather than computed and excluded from the composite — useful to speed up a run when you only need a subset. Leave all checked to compute everything (default).

Runs locally in this process — the same pipeline as the command-line tool. Use the "Compute GVI" button in the top bar to run.
